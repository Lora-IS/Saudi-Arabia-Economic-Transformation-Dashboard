# 🇸🇦 Saudi Arabia — A Nation in Transformation

## Overview

An interactive Power BI dashboard analyzing Saudi Arabia's real GDP transformation between 2010 and 2025 using official data from the General Authority for Statistics (GASTAT).

The dashboard explores overall GDP growth, the expansion of the non-oil economy, oil vs. non-oil sector performance, and annual GDP growth trends.

## Dashboard Preview

![Saudi Arabia Economic Transformation Dashboard](images/dashboard.png)

## Key Insights

- **Real GDP reached 4.91M Million SAR in 2025**
- **Overall GDP increased by 77.2% between 2010 and 2025**
- **Non-oil GDP increased by 111.4% over the same period**
- **Non-oil GDP represented 68.1% of GDP in 2025**
- GDP experienced a notable contraction in 2020, followed by strong recovery in subsequent years.

## Dashboard

The dashboard includes:

- Real GDP Trend (2010–2025)
- Oil vs. Non-Oil GDP Comparison
- GDP Year-over-Year Growth
- Key Economic Performance Indicators

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Transformation & Modeling

## Data Source

**General Authority for Statistics (GASTAT) — Saudi Arabia**

Data period: **2010–2025**

Dataset: Real GDP by institutional sectors, chain-linked volumes.

Unit: **Million SAR**

## Project Objective

This project was created to transform official economic data into a clear and interactive visual story, highlighting Saudi Arabia's economic transformation and the growing contribution of the non-oil economy.
